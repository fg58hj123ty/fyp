Final Year Project 2024 - 2025

Voice-Activated Home Security with Speech Anti-spoofing on NVidia Jetson Devices

This is a development and testing application created as part of our Final Year Project at Hong Kong Metropolitan University. The system explores the implementation of voice biometric authentication with anti-spoofing capabilities on NVidia Jetson devices.

Project Purpose

This application serves as a development and testing platform for:

  • • Voice biometric authentication research
  • • Speech anti-spoofing techniques
  • • Integration with NVidia Jetson devices
  • • Home security applications
